# dejaview-nsu.github.io

Лендинг проекта **DejaView** — мультимодальный поиск фильмов по обрывку воспоминания: текст, кадр, видео или звук. Проект ФИТ НГУ.

🌐 **Сайт:** https://dejaview-nsu.github.io

## Обновить сайт
Отредактируй `index.html` и запушь:
```bash
git add -A && git commit -m "update" && git push
```
Изменения появятся через ~1 минуту. Сборка не нужна — это статика (`index.html` открывается локально двойным кликом).
